How this register was obtained

La página oficial de aportaciones no sirve ni una base de datos ni un fichero de datos. Carga un marco con una aplicación alojada en otro dominio, y el corpus entero viaja incrustado como texto dentro de uno de sus ficheros de programa, que el navegador trocea al vuelo. El nombre de ese fichero cambia cada vez que la aplicación se reconstruye, de modo que tampoco él tiene una dirección estable.

The official contributions page serves neither a database nor a data file. It loads a frame holding an application on another domain, and the entire corpus travels embedded as text inside one of its program files, which the browser splits up on the fly. The name of that file changes every time the application is rebuilt, so not even it has a stable address.

Lo que sigue permite a cualquiera repetir la extracción y obtener las mismas huellas.
